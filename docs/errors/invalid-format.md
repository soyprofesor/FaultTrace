# invalid_format

**Invalid data** · HTTP 400 · Retry makes sense: No

## What it means

A value has the wrong format, such as text in a number field or an invalid date.

## What to do

Ask the user to correct the value.

## Where it comes from

`ORA-01722`, `ORA-01438`, `ORA-01830`, `ORA-01861`, `ORA-01840`.
